# Jannat Report Automation — пилот

Пилот обрабатывает единый Excel коммерческого директора, пересчитывает показатели из строк менеджеров, выявляет расхождения и формирует `public/index.html`.

## Проверка на GitHub

1. Оставьте репозиторий `SMD-jannat/jannat-report-automation` приватным.
2. Распакуйте ZIP, откройте репозиторий → **Add file → Upload files**.
3. Перетащите всё содержимое папки, включая `.github`, и нажмите **Commit changes**.
4. Откройте **Actions → Process Jannat report → Run workflow**.
5. После завершения откройте запуск и скачайте artifact `jannat-consolidated-report`.

Тестовый файл уже лежит в `sample_input`. В отчёте нет токенов и паролей.

## Что проверяется

- сумма строк менеджеров против строки ИТОГО;
- звонки четырёх B2B-менеджеров против KPI;
- встречи против детализации;
- выручка дня против детализации;
- заполнение онлайн-листа;
- месячный план/факт и пайплайн.

Коммерческий отчёт не содержит расходов и GOP, поэтому финансовая формула `Доходы − Расходы = GOP` для него неприменима. Она будет включена при подключении GM-отчётов.

## Полная автоматизация Telegram

Следующий этап описан в `cloudflare_patch/README.md`. Worker должен сохранить Telegram `file_id`, запустить GitHub Action и после обработки показать ссылку боту. Для этого понадобятся новые секреты, их нельзя отправлять в чат или коммитить в GitHub.
